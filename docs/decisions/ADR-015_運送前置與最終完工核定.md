# ADR-015：運送前置與最終完工核定

- 狀態：Accepted
- 日期：2026-08-08
- 決策者：使用者（代表公司需求）
- 對應：P0-03、PROD-003、INV-001

## 1. 決策

1. 一般製程完成不產生庫存。
2. 第一版以「運送」製程完成作為最終完工核定的前置條件。
3. 運送完成本身不自動入庫；具權限者必須執行獨立 `record_final_completion` command。
4. command 同一交易建立 `final_completion_entry` 與正向 `inventory_ledger`，並保存數量、人員、時間、運送事件及稽核關聯。
5. 一次核定代表一批實際完工，不自動把整張工單永久標為完成。

## 2. 理由

舊系統只在運送完成且有完工量時把數量送入待出貨存貨。新版保留這個安全邊界，同時把「製程完成」與「核定入庫」分成可稽核事件，避免誤觸自動增加庫存。

## 3. 重新評估

公司提供無運送製程但仍需完工入庫的實際類型時，另定這些類型的前置條件，不放行任意一般製程入庫。
