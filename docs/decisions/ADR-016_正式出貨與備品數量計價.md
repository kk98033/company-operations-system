# ADR-016：正式出貨與備品數量計價

- 狀態：Accepted
- 日期：2026-08-08
- 決策者：使用者（代表公司需求）
- 對應：P0-04、SHIP-003、PRICE-005

## 1. 決策

1. 正式出貨量、備品量與實際扣庫量分欄保存。
2. `實際扣庫量＝正式出貨量＋備品量`，兩者都消耗同一工單的可出貨量。
3. 出貨單顯示正式量、備品量及實際交付總量。
4. 基礎計價預設只使用正式出貨量。備品只有在計價明細明確填入可請款數量與單價時才收費，不因實際交付就靜默收費。
5. 舊資料依原計價紀錄匯入，不用新規則回算並改寫歷史金額。

## 2. 理由

舊系統可證明正式量與備品量都扣可出貨量，但備品計價存在兩條不一致程式路徑。新版選擇避免免費備品被靜默收費，又不扭曲實際交付數量的方案。
