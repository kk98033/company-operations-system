# ADR-012：工單製版欄位範圍

- 狀態：Accepted
- 日期：2026-08-07
- 決策者：使用者（代表公司需求）
- 對應：P0-08、WO-003、WO-004、WO-012、MASTER-004

## 1. 證據

已逐頁核對 Gmail 中的工單建檔、註解、範例、工單列印、列印範例及 `系統修改.jpg`。

證據顯示：

- 新工單建檔畫面仍有「製版」製程，並有協力廠、說明、新版、舊版、天地輪轉與左右輪轉。
- 工單範例同時選了「新版」與「左右輪轉」，證明版本與輪轉方向是兩個維度，不是四選一。
- 工單列印範例也會顯示製版協力廠與「新版、左右輪轉」。
- `系統修改.jpg` 要求刪除的是獨立「色別設定／裁紙設定」，不是整個工單製版或印刷規格。

## 2. 決策

1. 工單保留「製版」製程列：協力廠、製程說明、製版類型、輪轉方向。
2. `plate_version` 是獨立單選：`new`／`existing`；`plate_rotation` 是另一組獨立單選：`top_bottom`／`left_right`。不得用一個四選一欄位表示。
3. 附件沒有規定預設值或必填；第一版兩組都不預選且允許為空，後端不自行推斷。
4. 版費是獨立金額，保留在工單基本資料與報價明細，不藏入製程備註。
5. 正反面 CMYK、色數與特別色是「印刷規格」，保留在工單內。
6. 不建立獨立色別設定、裁紙設定、曬版、代版或留版的新編輯介面。
7. 舊資料若含曬版、代版、留版、舊色別或裁紙值，匯入後仍以只讀歷史文字顯示，不丟棄也不重建停用設定模組。

## 3. 實作與驗收

- `/work-orders/new` 的製版列將兩組選項分開，且不預選。
- 工單詳情、編輯與 A4 列印使用相同語意。
- 測試要覆蓋「新版＋左右輪轉」與「舊版＋天地輪轉」，並允許兩組都空白。
- 專案導覽不出現色別設定或裁紙設定頁面。

## 4. 重新評估條件

只有公司提供新簽認樣張，明確要求必填、其他製版選項或恢復停用功能時，才以新 ADR 取代本決策。
