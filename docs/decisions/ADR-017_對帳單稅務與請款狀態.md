# ADR-017：對帳單稅務與請款狀態

- 狀態：Accepted
- 日期：2026-08-08
- 決策者：使用者（代表公司需求）
- 對應：P0-06、P0-07、BILL-003、BILL-004

## 1. 決策

1. 新版報價與工單不顯示或自動計算稅額。
2. 第一版只有一種正式 `statement`／「對帳單」文件與列印模板。
3. 「待請款、已請款」是對帳單流程狀態，不另建內容重複的請款單資料模型。
4. 對帳單保留可選計稅，新單預設關閉。啟用時才設定稅率與取整政策；發行時保存完整金額快照。
5. 不把舊版固定 5% 硬編為新版永久規則。舊稅務、取整及歷史總額原樣保留並可核對。
6. 公司日後提供不同請款格式時，共用同一帳款資料增加第二種模板，不複製帳款表。

## 2. 後續驗收

對帳單 A4 排版、實際稅率／取整案例與印表機仍在 Phase 8 使用去識別 fixture 及實印 UAT 簽認；這不改變單一 statement 模型決策。
