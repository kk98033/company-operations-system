- CSRF／來源：`company_system_csrf` 是由必要 `CSRF_HMAC_KEY` 簽章並綁定 Session digest 的 43 字元 token；unsafe request 同時核對 readable Cookie、`X-CSRF-Token` 與伺服器 HMAC。登入／登出 exact-match 單一 `APP_PUBLIC_ORIGIN`，缺 Origin 時只接受同源 Referer，缺兩者時 fail closed；不使用 wildcard、Host 推導或寬鬆 CORS。
- API：登入 JSON 不再回 raw token／token type；OpenAPI 與 Orval 由 `SessionBearer` 改為 `SessionCookie`，generated client 不含 Authorization 或 raw credential。登出在有有效格式 Cookie 時必須先通過 signed CSRF，撤銷成功後才清兩個不同 path 的 Cookie；無／畸形 Cookie則冪等清除並回 204，DB 失敗不得先清 Cookie。
- Session dependency：只接受 Cookie，不 fallback Bearer；missing、malformed、unknown、expired、revoked 或 inactive identity 都使用同一 401。正式 `GET /auth/session` 與 React 登入頁依計畫留在 1.5，未提前擴張公開 API。
- 設定：新增 `APP_PUBLIC_ORIGIN` 與 SecretStr `CSRF_HMAC_KEY` fail-fast；production 拒絕 HTTP origin，範例／短密鑰被拒絕且錯誤不回顯值。本機 `.env` 必須自行產生 token_urlsafe(32) 密鑰，不提交 Git。
