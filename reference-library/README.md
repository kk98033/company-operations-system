# 公司系統說明與參考資料庫

整理日期：2026-10-12

這個資料夾集中保存公司管理系統的架構、需求、實作規格、舊系統分析與影音參考。內容是可放入公開 GitHub repository 的整理版，不包含正式客戶資料、交易明細、資料庫匯出、Secret、原始附件或可辨識個資。

## 閱讀順序

1. `00_目前進度摘要.md`：目前完成範圍、阻擋與下一步。
2. `01_專案基準/`：公司流程、最終架構、實作計畫與開工檢查表。
3. `02_系統規格/`：需求、資料模型、UI、測試、資安、部署與移轉規格。
4. `03_架構決策/`：ADR 架構與業務決策。
5. `04_舊系統與需求分析/`：從操作影片、舊程式及 Gmail 樣稿整理出的分析。
6. `05_版面參考/`：不含原始資料檔的版面與畫面索引。
7. `06_影片參考/`：兩支重建參考影片、逐字稿及字幕。

## 文件效力

若內容衝突，依序以 `01_專案基準/`、`02_系統規格/`、`03_架構決策/` 為準；`04_舊系統與需求分析/` 與影音只作證據和操作理解用途。
