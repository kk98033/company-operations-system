# ADR-018：新舊文件單號

- 狀態：Accepted
- 日期：2026-08-08
- 決策者：使用者（代表公司需求）
- 對應：P0-09、DOC-001

## 1. 新版顯示單號

| 文件 | 格式 | 流水重置 |
|---|---|---|
| 報價 | `QUO-YYYYMMDD-SS` | 每日 |
| 案件 | `CASE-YYYYMMDD-SSS` | 每日 |
| 工單 | `WO-YYYYMMDD-SSS` | 每日 |
| 出貨 | `SHP-YYYYMM-SSS` | 每月 |
| 計價 | `PRC-YYYYMMDD-SSS` | 每日 |
| 對帳 | `STM-YYYYMM-SSS` | 每月 |
| 收款 | `RCT-YYYYMMDD-SSS` | 每日 |

`SS` 從 `01` 開始，`SSS` 從 `001` 開始。流水以公司、文件類型與表中日／月期間分開，必須在資料庫交易內並行安全配發。

## 2. 共同規則

1. 內部關聯使用不可變 ID，不使用顯示單號當主鍵。
2. 文件日期修改不重編號；作廢號不回收；另存新檔一定取得新號。
3. 同公司與文件類型的顯示單號唯一。
4. 舊資料保存 `legacy_document_number`、`legacy_source_table` 與 `legacy_source_key`，畫面標示「舊系統」並可搜尋。
5. 舊號不補英文前綴、不覆寫、不因新號格式回算。

## 3. 異常

當固定位數在當日／月耗盡時，必須回傳明確錯誤並通知管理者，不得靜默擴位、重用或產生重號。若實際單量接近上限，公司必須在上線前重新簽認位數。
