# ADR-027：可還原備份策略

> 日期：2026-08-20
> 狀態：Accepted（正式採 Cloud SQL 或自管 PostgreSQL於 Phase 11 成本評估決定）

## 決策

1. 採 3-2-1 並保留公司可控制的離線／不可變副本；Git、VM snapshot 或同機資料夾都不能單獨稱為正式備份。
2. 備份必須一起涵蓋 PostgreSQL、附件／PDF、object manifest、程式版本、migration、非秘密設定與 Secret 重建／輪替手冊。
3. 正式推薦 Cloud SQL automated backup＋PITR，另做每日加密 logical dump；預算採自管時必須使用 base backup＋WAL archive 及成熟工具，不能只靠 `pg_dump`。
4. Secret 存 Secret Manager；不進 Git、image 或普通備份包。公司另保存緊急復原權限與輪替程序。
5. 每日驗證、每月隔離 DB 還原、每季完整乾淨環境演練；記錄實際 RPO／RTO。沒有成功還原證據就不能標示備份完成。

## 目標

Managed 方案目標 RPO ≤ 15 分鐘、RTO ≤ 4 小時；實際結果以 Phase 11 演練報告為準，不把設定值冒充已達成。
