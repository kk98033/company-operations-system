# 印刷業整合管理系統：頁面元素與排列規格

版本：UI 規格 v1.0
依據：完整流程影片、Gmail 修改文件、舊系統畫面與《完整流程與功能需求》

## 1. 設計目標

### 1.1 核心原則

1. 工單資料很多，但仍依 Gmail 要求維持「單一頁面」；使用明確區塊、區塊編號與頁內導覽，不拆成多個需要來回切換的獨立表單。
2. 每個流程只輸入本階段新增的資料：
   - 工單輸入規格。
   - 完工回報只輸入本次完工量。
   - 出貨只輸入本次出貨量與物流資訊。
   - 計價只確認數量與價格。
3. 所有列表都提供關鍵字查詢，符合「搜尋內容細一點」的要求。
4. 單號、客戶、品名、日期、數量與狀態永遠是畫面的第一視覺層級。
5. 價格、版費、刀模費只對有權限的人顯示。
6. 不以顏色作為唯一狀態提示；顏色旁必須顯示狀態文字。
7. 優先支援公司辦公室桌機；生產與出貨頁另外支援平板。

### 1.2 建議尺寸

- 桌面主要設計：1440 × 900。
- 最低桌面寬度：1024。
- 平板：768–1023。
- 手機：320–767，只提供查詢、查看、完工回報與出貨確認等簡化工作；完整工單建檔仍以桌面／平板橫向為主。
- 表單內容最大寬度不鎖死，利用可用空間降低上下捲動量。

## 2. 全站框架

### 2.1 左側主導覽

桌面固定顯示，寬約 220–240 px；平板收合為圖示列；手機改為抽屜選單。

順序：

1. 首頁
2. 客戶
3. 工單
4. 生產
5. 出貨
6. 計價
7. 報價
8. 帳款
9. 報表
10. 主檔
11. 系統設定

每個選單使用圖示＋文字。展開中的模組顯示子選單，例如：

```text
工單
├─ 工單列表
├─ 新增工單
└─ 歷史工單

生產
├─ 製程監控
└─ 完工回報紀錄

出貨
├─ 出貨單列表
└─ 新增出貨單

計價
├─ 待計價
├─ 計價查詢
└─ 價格歷史
```

### 2.2 頂部列

由左至右：

- 全域搜尋。
- 快速新增按鈕。
- 待辦／通知。
- 使用者姓名與目前角色。
- 個人選單。

全域搜尋 placeholder：

> 搜尋工作單、出貨單、客戶、品名、客戶單號

搜尋結果依種類分組：

- 工單
- 出貨單
- 報價單
- 客戶

每筆顯示單號、客戶、品名、日期、狀態，按 Enter 開啟第一筆，方向鍵可選結果。

### 2.3 頁面標題列

每頁固定排列：

```text
[頁面名稱＋狀態]                     [次要動作] [主要動作]
[一行用途、篩選摘要或最後更新資訊]
```

範例：

```text
工單建檔  [草稿]           [取消] [列印預覽] [儲存工單]
工作單號將於首次儲存後自動產生
```

一頁只能有一個最高優先主要按鈕。

## 3. 共用元件規格

### 3.1 狀態標籤

工單：

- 草稿
- 已開單
- 生產中
- 部分完工
- 已完工
- 部分出貨
- 已出貨
- 部分計價
- 已計價
- 已結案
- 作廢

單據狀態標籤必須同時包含文字與圖示；例如逾期使用警示圖示＋「逾期」，不能只有紅色底。

### 3.2 數量摘要列

製程、出貨及計價詳情頁上方共用：

```text
訂單量 | 累計完工 | 可出貨 | 累計出貨 | 未出貨 | 已計價 | 待計價
```

桌面橫向排列；平板折為兩列；手機垂直排列。數字靠右並使用千分位。

### 3.3 查詢列

排列順序：

1. 最常使用的條件。
2. 日期區間。
3. 狀態。
4. 關鍵字。
5. 查詢按鈕。
6. 清除條件。
7. 更多條件。

查詢必須保留在網址 query string，返回列表時不會遺失條件。

### 3.4 資料表

共同行為：

- 表頭固定。
- 可排序欄位顯示排序符號。
- 每頁預設 30 筆，可選 30、50、100。
- 點整列進詳情；最後一欄保留更多操作。
- 支援欄位顯示／隱藏。
- 匯出只匯出目前篩選結果。
- 空資料顯示「目前沒有符合條件的資料」，並提供清除條件。
- 載入中使用表格骨架，不讓欄寬跳動。

### 3.5 數值輸入

- 數量：整數、千分位、靠右。
- 單價：小數二位、靠右。
- 金額：小數二位，列表可視公司習慣顯示整數。
- 尺寸：分成長、寬、單位，顯示時組合為 `260 × 180 mm`。
- 不允許使用負數，只有「調整／退貨」流程可使用負數並要求原因。

### 3.6 自動帶入欄位

自動帶入後：

- 顯示來源，例如「來自客戶主檔」。
- 使用者仍可修改的欄位使用一般輸入框。
- 不允許修改的欄位使用唯讀樣式，不要使用灰到看不清的 disabled。
- 若主檔沒有資料，明確顯示「客戶主檔未設定電話」並提供前往編輯。

### 3.7 危險操作

作廢、刪除附件、退回狀態、覆蓋價格等操作：

- 不放在主要按鈕旁。
- 收在「更多」選單。
- 開啟確認視窗。
- 要求填寫原因。
- 顯示此操作會影響的出貨／計價／應收資料。

## 4. 登入頁

### 4.1 排列

桌面左右兩區：

- 左側：公司名稱、系統名稱、簡短說明。
- 右側：登入表單。

表單元素：

- 帳號。
- 密碼。
- 顯示密碼按鈕。
- 記住帳號。
- 登入。
- 忘記密碼或聯絡管理員。

錯誤訊息顯示於欄位下方，不使用只有「登入失敗」的籠統訊息。

## 5. 首頁工作台

### 5.1 頂部

- 問候語＋日期。
- 新增工單。
- 新增報價。
- 依角色顯示新增出貨或完工回報。

### 5.2 第一列摘要

最多四張：

- 今日待交。
- 已完工待出貨。
- 已出貨待計價。
- 逾期未收。

點擊摘要直接帶入對應列表篩選。

### 5.3 主要內容

左側約 65%：

- 近期交貨表。
- 欄位：工作單號、客戶／品名、交貨日期、訂單量、完工量、狀態。
- 逾期置頂。

右側約 35%：

- 製程負荷。
- 待辦事項。
- 備份狀態只對管理員顯示。

首頁不放完整報表，避免資訊過載。

## 7. 工單頁面

### 7.1 工單列表 `/work-orders`

標題列：

- 工單列表。
- 新增工單。

第一層快速篩選：

- 全部。
- 今日待交。
- 生產中。
- 可出貨。
- 已逾期。
- 已結案。

查詢列：

- 客戶。
- 訂購日期區間。
- 交貨日期區間。
- 工單狀態。
- 目前製程。
- 關鍵字。

關鍵字搜尋：

- 工作單號。
- 客戶名稱。
- 客戶單號。
- 品名。
- 工單備註。
- 刀模號碼。

表格欄位：

- 工作單號。
- 建檔日期。
- 客戶名稱。
- 客戶單號。
- 品名。
- 訂單數量。
- 交貨日期。
- 目前製程。
- 完工量。
- 已出貨量。
- 單價。
- 版費。
- 刀模費。
- 狀態。

單價、版費與刀模費依 Gmail 要求加入；沒有價格權限的角色整欄隱藏。

列操作：

- 查看。
- 編輯。
- 複製成新工單。
- 列印。
- 更多：作廢、查看異動。

### 7.2 新增／編輯工單

依 Gmail 要求為單一頁面，但增加位於內容上方的頁內導覽：

```text
客戶與訂單 | 備紙 | 印刷規格 | 製程 | 備註與圖片
```

點擊只捲動到區塊，不切換／隱藏資料。

#### A. 標題與動作

左側：

- 工單建檔。
- 草稿／目前狀態。
- 工作單號。
- 最後儲存時間。

右側：

- 另存新檔。
- 取消。
- 列印預覽。
- 儲存工單。

頁面最下方重複同一組動作，符合 Gmail 文件。

#### B. 客戶與訂單

桌面四欄排列：

第一列：

- 客編（搜尋式下拉，必填）。
- 客名（自動帶入，占兩欄）。
- 工作單號（唯讀）。

第二列：

- 客戶單號。
- 聯絡人。
- 電話。
- 訂購日期（預設今日，可修改）。

第三列：

- 地址（占兩欄）。
- 交貨日期。
- 業務／承辦人。

第四列：

- 品名（占兩欄）。
- 訂單數量。
- 計量單位。

第五列：

- 單價。
- 版費。
- 刀模費。
- 報價單來源。

規則：

- 工作單號首次存檔時建立，格式預設 `YYMMDD + 3 碼流水號`。
- 變更客戶時提示會重新帶入客戶資料，但不直接覆蓋使用者已修改的地址。
- 交貨日期早於訂購日期時禁止儲存。
- 單價固定顯示二位小數。

#### C. 備紙

桌面並排三欄：面紙、底紙、浪紙。

每欄頂部：

- 啟用此紙材的開關。
- 從主檔選擇。

面紙／底紙欄位：

- 供應商。
- 紙質。
- 廠別。
- 尺寸長。
- 尺寸寬。
- 數量。
- 備註。

浪紙欄位：

- 供應商。
- 紙質／楞浪種類。
- 尺寸長。
- 尺寸寬。
- 數量。
- 備註。

規則：

- 工單允許只有面紙。
- 關閉底紙／浪紙時不顯示其必填錯誤。
- 供應商、紙質、廠別來自主檔。
- 可使用「從歷史工單帶入」。

#### D. 印刷規格

第一列：

- 印刷尺寸長、寬。
- K 數。
- 模數。

第二列：

- 基本印刷量。
- 加放量。
- 系統計算印刷總量。
- 計算說明。

第三列：

- 新版／舊版。
- 天地輪轉／左右輪轉。
- 刀模號碼。

正反面左右並排：

- 色數。
- C、M、Y、K 勾選。
- 特別色多筆輸入。
- 每個特別色可選 Pantone 或自由輸入。

規則：

- 勾選的 CMYK 數量與色數不一致時警告。
- 加放量不可造成總量小於訂單需求。
- 自動公式仍應允許授權人員覆寫，但要留下原因。

#### E. 製程

使用兩欄表格型排列，每個製程一列：

```text
[製程名稱] [協力廠] [製程設定] [備註]
```

製程：

- 美工。
- 輸出。
- 製版。
- 打樣。
- 印刷。
- 上光。
- 裱紙。
- 模具。
- 軋型。
- 加工。
- 糊邊。
- 運送。
- 其他。

特殊欄位：

- 製版：新版／舊版、天地／左右輪轉。
- 上光：上光種類。
- 軋型：刀模號碼、模數。
- 糊邊：裝箱／裝袋及每箱／每袋數量。
- 運送：預計日期、送貨地點。

每列前方增加「需要此製程」開關。未啟用的製程不列印、不參與進度。

#### F. 備註與圖片

左右兩欄：

- 左：工單整體備註。
- 右：圖片附件。

備註：

- 至少支援 150 字元；實作建議最大 2,000 字。
- 顯示目前字數。
- 保留換行與空白字元。

圖片：

- 拖放或選檔。
- 支援 JPG、PNG、PDF。
- 縮圖。
- 檔名。
- 上傳人與時間。
- 設為工單列印主圖。
- 刪除。

#### G. 儲存驗證摘要

按儲存若有錯誤：

- 頁首顯示錯誤數量。
- 列出區塊與欄位。
- 點擊錯誤可捲動到欄位。
- 欄位下顯示實際錯誤原因。

不可只跳出「資料有誤」。

### 7.3 工單詳情

預設唯讀，避免觀看時誤改。

頂部：

- 工作單號。
- 狀態。
- 客戶、品名、交期。
- 編輯。
- 複製工單。
- 列印。
- 更多。

第一列顯示數量流程。

下方：

- 工單規格。
- 製程時間軸。
- 出貨紀錄。
- 計價紀錄（依權限）。
- 附件。
- 異動紀錄。

### 7.4 歷史工單

查詢條件以品名與客戶優先。

列操作：

- 查看。
- 複製為新工單。
- 比較新舊版本。

複製確認視窗列出：

- 會複製：客戶、品名、備紙、印刷規格、製程、備註。
- 不複製：工作單號、日期、數量、狀態、完工、出貨、計價。
- 圖片由使用者勾選是否複製。

### 7.5 工單列印預覽

左側工具列：

- A4／實際紙張。
- 縮放。
- 顯示／隱藏價格。
- 顯示／隱藏圖片。
- 下載 PDF。
- 列印。

右側：

- 完整列印預覽。

列印內容依 Gmail `工單列印-範例.pdf`，固定保留：

- 公司資訊。
- 工作單號、訂購日、交貨日。
- 客編、客戶單號。
- 品名、數量。
- 紙材。
- 正反面印刷。
- 全部啟用的製程。
- 備註與圖片。

快速篩選：

- 可出貨。

進階條件：

- 交貨日期。
- 客戶。
- 製程。
- 協力廠。
- 狀態。
- 關鍵字。

表格：

- 工作單號。
- 客戶／品名。
- 交貨日期。
- 目前製程。
- 協力廠。
- 訂單量。
- 累計完工。
- 可出貨。
- 已出貨。
- 狀態。

### 8.2 完工回報視窗

頂部唯讀摘要：

- 工作單號。
- 客戶。
- 品名。
- 訂單量。
- 目前累計完工。

輸入：

- 完工日期時間。
- 本次完工量。
- 良品量。
- 損耗量。
- 完成製程。
- 下一製程。
- 備註。

即時計算：

- 回報後累計完工。
- 新增可出貨量。
- 未完工量。

規則：

- 本次完工量不能為 0。
- 良品＋損耗需等於本次生產量；實際公司公式待確認。
- 超過訂單量時顯示警告並要求原因。
- 儲存後直接更新出貨可用量，不需再進其他畫面更新。

### 8.3 製程時間軸

每個工單顯示：

- 製程名稱。
- 協力廠。
- 預計日期。
- 開始時間。
- 完成時間。
- 回報人。
- 狀態。
- 備註。

### 17.1 平板

## 18. 鍵盤與無障礙

- 所有輸入都有可見 label。
- 鍵盤 Tab 順序跟畫面由左至右、由上至下相同。
- Enter 不直接提交長表單，避免誤存。
- Ctrl/Cmd + S 可儲存草稿。
- 日期、下拉、對話框均可鍵盤操作。
- 錯誤訊息不只靠顏色。
- 表格列可聚焦並以 Enter 開啟。
- 觸控按鈕最小高度建議 44 px。
