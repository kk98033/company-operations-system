## 1. 系統用途

本系統是印刷／紙器公司的接單、生產與帳務整合系統。主要作業鏈為：

> 建立工單／製程傳票 → 備紙與印刷規格 → 各製程及協力廠 → 完工數量回報 → 出貨 → 計價 → 應收／請款 → 歷史查詢

「報價單」是接單前或獨立進行的流程，可依客戶與品項建立並列印 A4 報價單。

## 2. 現行端到端流程

### 2.1 維護主檔

作業人員先在基本資料／基礎設定維護可重複選用的資料：

- 客戶資料
- 供應商、紙張供應商
- 紙質、紙張磅數、廠別
- 面紙、底紙、浪紙資料
- 上光種類
- 楞浪種類
- 各製程協力廠
- 刀模資料
- 使用者及系統參數

影片顯示目前已有部分下拉選項，但仍有不少資料必須手動輸入。新系統應讓常用資料可搜尋選取並自動帶入。

### 2.2 建立工單／製程傳票

1. 建立新工單。
2. 輸入客戶編號，系統帶入客名、電話、聯絡人與地址。
3. 填寫客戶單號、品名、訂單數量、訂購日期與交貨日期。
4. 系統產生工作單號。
5. 視需要填寫單價、版費與刀模費。
6. 填寫備紙：
   - 面紙：供應商、紙質、廠別、尺寸、數量、備註。
   - 底紙：供應商、紙質、廠別、尺寸、數量、備註。
   - 浪紙：供應商、紙質、尺寸、數量、備註。
   - 有些工單只有面紙，不一定同時有底紙及浪紙。
7. 填寫印刷規格：
   - 印刷尺寸。
   - K 數／開數。
   - 模數。
   - 印刷數量與加放量（±量）。
   - 正面、反面色數。
   - C、M、Y、K 與特別色。
8. 選擇新版或舊版，以及天地輪轉／左右輪轉等製版方式。
9. 填寫各製程：
   - 美工
   - 輸出
   - 製版
   - 打樣
   - 印刷
   - 上光
   - 裱紙
   - 模具
   - 軋型
   - 加工
   - 糊邊
   - 運送
   - 其他
10. 每個製程可選協力廠並填寫備註；上光另選上光種類；軋型填刀模號碼與模數；糊邊可選裝箱或裝袋。
11. 填寫工單整體備註並附上產品／刀模圖片。
12. 存檔或另存新檔，並列印工單交付內部或協力廠作業。

影片中的數量換算例子：訂單／基本數量約 1,400，再加放 100，印刷數量成為 1,500；實際公式仍需依 K 數／開數與公司規則確認。

### 2.3 重複訂單與歷史資料

- 作業人員會查詢以前做過的品項，參考或沿用舊工單資料。
- 已出貨／結案的資料會進入歷史資料。
- 新系統應支援「複製歷史工單建立新工單」，但必須產生新工作單號，並讓日期、數量、價格與製程重新確認。
- 查詢需要客戶、日期、單號及關鍵字，不應只能用固定欄位精確查詢。

### 2.4 製程監控與完工回報

1. 工單存檔後，工作單號會出現在製程監控／製程管理。
2. 生產完成或準備出貨時，作業人員找到該工作單。
3. 輸入完工數量／可出貨數量。
4. 系統依完工量提供後續出貨可選數量。

現行系統的完工量、出貨量及剩餘量需要在不同畫面重複更新，容易不一致。

### 2.5 建立及列印出貨單

1. 從製程監控完成數量更新後，進入出貨作業。
2. 選取可出貨的工單／品項。
3. 輸入本次出貨數量；必要時填備品量、單價及備註。
4. 存檔並列印出貨單。
5. 支援一張工單分批出貨。
6. 出貨完成後，現行操作還要回製程監控更新數量。

新系統應在出貨單存檔時自動完成下列連動：

- 累計已出貨量。
- 計算未出貨量。
- 更新工單為未出貨、部分出貨或全部出貨。
- 產生待計價項目。
- 保留每次出貨紀錄，不覆蓋舊數量。

### 2.6 計價

1. 已出貨的單據出現在計價作業清單。
2. 未計價與已計價資料以顏色區分。
3. 作業人員選取尚未計價的出貨項目。
4. 確認或修改計價數量。
5. 輸入單價；視案件輸入版費、刀模費或其他加工費。
6. 系統計算價格小計與合計。
7. 完成計價後，狀態改為已計價。
8. 計價完成後可產生請款單，並提供後續應收使用。

影片明確反映現行痛點：出貨後還必須再到其他畫面重複選單、輸入數量與單價。公司希望出貨後系統能直接記住該筆資料及價格，不必再跑一輪計價作業。由於影片中也確認價格可能修改，新系統應自動帶入報價、工單或客戶／品項最近一次單價，但允許有權限者修改並留下價格異動紀錄。

### 2.7 應收與帳款

1. 已計價資料進入應收／帳款作業。
2. 依客戶與期間彙整請款。
3. 產生應收單／對帳資料。
4. 登錄收款並追蹤未收及逾期款項。

影片主要示範到計價操作；應收的完整列印、發票與沖帳規則仍需財務人員確認。

## 3. Gmail 文件指定的修改需求

### 3.1 工單建檔畫面

- 原本分開的工單畫面合併成一個頁面。
- 版面與欄位順序依 `工單建檔作業-註解.pdf` 右側設計。
- 頂部及底部均提供：
  - 另存新檔
  - 存檔
  - 取消
  - 列印
- 工作單號自動產生：
  - 年月日加三碼流水號。
  - 文件例：`260427001`。
- 訂購日期自動帶入當天日期，但允許修改。
- 輸入客編後自動帶入：
  - 客名
  - 電話
  - 聯絡人
  - 地址
- 單價保留小數點第二位。
- 供應商由主檔帶入。
- 紙質由紙質設定帶入。
- 廠別由廠別設定帶入。
- 上光由上光種類設定帶入。
- 各製程可帶入協力廠資料。
- 備註至少支援 150 個字元，並保留空白字元。
- 支援上傳／顯示圖片。
- 表單使用清楚的單選、複選及下拉元件。

### 3.2 工單欄位

基本資料：

- 客編、客名
- 客戶單號
- 電話、聯絡人、地址
- 工作單號
- 品名
- 訂單數量
- 訂購日期、交貨日期
- 單價、版費、刀模費

備紙：

- 面紙：供應商、紙質、廠別、尺寸、數量、備註
- 底紙：供應商、紙質、廠別、尺寸、數量、備註
- 浪紙：供應商、紙質、尺寸、數量、備註

印刷：

- 印刷尺寸
- K 數
- 模數
- 數量
- ±量
- 正面色數、CMYK、特別色
- 反面色數、CMYK、特別色

製程：

- 圖片附件

### 3.3 工單列印

依 `工單列印-範例.pdf` 製作固定版型，內容包括：

- 公司名稱、電話、傳真、地址與 Email。
- 工作單號、訂購日期、交貨日期。
- 客編、客戶單號。
- 品名、數量。
- 面紙、底紙、浪紙資料。
- 製版、打樣。
- 正反面印刷尺寸、數量、加放、K 數、模數與色彩。
- 上光、裱紙、軋型、加工、糊邊及其他製程。
- 備註。
- 產品／刀模圖片。

列印內容應直接使用已存檔資料，不可要求使用者重新輸入；列印前提供預覽及 PDF 下載。

### 3.4 報價單建檔

- 報價單號自動產生：
  - 年月日加兩碼流水號。
  - 文件例：`26042701`。
- 報價日期自動帶入當日，但允許修改。
- 輸入客編後自動帶入：
  - 客戶名稱
  - 聯絡人
  - 客戶電話
  - 客戶傳真
  - 客戶地址
- 報價明細列可自動遞增。
- 明細欄位：
  - 品名
  - 尺寸
  - 紙質
  - 顏色
  - 上光
  - 版費
  - 刀模費
  - 數量
  - 單價
  - 附註
- 單價保留小數點第二位。
- 報價單另有整體備註。
- 提供另存新檔、存檔、取消及列印。
- 報價單列印版型為 A4。

### 3.5 查詢功能修改

- 搜尋條件增加「關鍵字查詢」。
- 關鍵字至少搜尋：
  - 傳票／工作單號
  - 客戶名稱
  - 客戶單號
  - 訂貨／品名
  - 備註
- 支援客戶、日期區間、單號與關鍵字組合查詢。
- 查詢結果增加：
  - 客戶單號
  - 單價
  - 版費
  - 刀模費
- 可排序、分頁及匯出。

### 3.6 移除功能

新版不做：

- 色別設定
- 裁紙設定

移除前仍應檢查舊工單是否引用這些資料；歷史資料需保留顯示文字，不必保留新增／修改介面。

### 3.7 備份

- 增加雲端備份。
- 增加硬碟／本機或外接磁碟備份。
- 自動排程備份。
- 備份結果、檔案大小與失敗原因可查詢。
- 失敗時通知管理員。
- 定期執行還原演練；只有「可成功還原」才算有效備份。
- 雲端與本機備份應加密並限制存取權限。

## 4. 新系統必要的流程改善

### 4.1 單一資料來源

工單數量、完工量、出貨量與計價量必須來自同一組交易資料：

```text
訂單量
  → 完工回報（可多次）
  → 出貨明細（可分批）
  → 計價明細（可分批或合併）
  → 應收
```

系統自動計算：

- 累計完工量
- 可出貨量
- 累計出貨量
- 未出貨量
- 已計價量
- 待計價量

禁止用覆寫總數的方式記錄流程，必須保留每次異動。

### 4.2 狀態

工單建議狀態：

- 草稿
- 已開單
- 生產中
- 部分完工
- 已完工
- 部分出貨
- 已出貨
- 部分計價
- 已計價
- 已結案
- 作廢

狀態由實際交易自動推進；若允許人工退回，需填原因並留下稽核紀錄。

### 4.3 避免重複輸入

- 工單完工回報後直接提供出貨可用量。
- 出貨存檔直接扣除可出貨量並產生待計價資料。
- 計價直接沿用出貨客戶、品項與數量。
- 應收直接沿用已計價資料。
- 使用者只補充該階段新增的資訊，不重新輸入前一階段資料。

## 6. 權限與稽核

- 業務：客戶、報價、訂單／工單基本資料。
- 生管：工單規格、製程與完工回報。
- 出貨：出貨單。
- 會計：價格、計價、應收及收款。
- 主管：查詢、報表與必要的退回／作廢核准。
- 管理員：主檔、使用者、權限及備份。

價格與成本欄位不可讓所有現場人員看到。所有新增、修改、作廢、重印、狀態退回及價格修改都必須記錄使用者、時間、修改前後值與原因。

## 7. 尚需公司確認

- 工作單號使用民國年還是西元年；跨年度流水號是否重置。
- K 數／開數、模數、印刷數量與加放量的完整公式。
- 完工量是否允許高於訂單量及容許比例。
- 出貨量是否可高於完工量；備品量如何計算。
- 一張出貨單是否可包含多張工單。
- 計價可否合併多張出貨單；部分計價如何處理。
- 版費、刀模費是每張工單一次、每次出貨，或可分攤。
- 報價能否轉工單，以及轉換時哪些欄位需重新確認。
- 應收單、對帳單、發票及收款沖帳的實際規則。
- 雲端備份使用的服務、保存年限及還原目标時間。
