# Frontend

預定使用 React＋TypeScript＋Vite，負責桌面版頁面、表單、查詢、狀態與 A4 列印預覽。

目前尚未初始化框架。必須在 `04_開工前確認清單.md` 通過後，依 `03_最終實作計畫.md` Slice 0.1 建立，不可先在此放置未經計畫驗證的大量程式。

實作時必須：

- 依業務 feature 拆分。
- 使用 OpenAPI 產生的 API 型別。
- 不在前端保存最終庫存、稅額或權限真相。
- 每個頁面處理 loading、empty、error、permission 及 conflict。
- 以公司 Windows 桌機與實際印表機驗收。
